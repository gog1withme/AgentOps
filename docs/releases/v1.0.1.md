# AgentOps 1.0.1 — Trust & Intelligence Patch

**AgentOps 1.0.1** hardens the v1.0 foundation: honest MCP metrics, configurable model pricing, actionable Context Inspector analysis, self-update, and a richer session diff command.

**Install** · [CHANGELOG](../../CHANGELOG.md) · [v1.0.0 release notes](v1.0.0.md)

---

## What's new in 1.0.1

### Self-update

```bash
agentops upgrade --check   # see if a newer release exists
agentops upgrade           # download, verify checksum, replace binary
```

### Configurable model pricing

Cost estimates no longer rely on two hardcoded rate tiers. Bundled defaults cover common OpenAI and Anthropic models; override via `~/.agentops/pricing.json`:

```json
{
  "models": [
    {"pattern": "gpt-4o-mini", "input_per_token": 0.00000015, "output_per_token": 0.0000006}
  ]
}
```

`agentops doctor` reports how many models are configured and flags unknown models seen in the current session.

### Context Inspector intelligence

The dashboard Context Inspector now shows:

- Session summary cards (prompt tokens, LLM calls, avg efficiency)
- Callout banners for duplicate context and low-efficiency files
- Duplicate and noisy file tables

CLI equivalent:

```bash
agentops context summary
```

API: `GET /api/context/analysis`

### Honest MCP p95

MCP Health p95 is now computed from a rolling window of the last 100 calls per server. Previously the dashboard labeled the latest single-call latency as "p95".

### Richer session diff

```bash
agentops diff <session_a> <session_b>
```

Now includes per-type event counts, files touched with overlap count, model breakdown, and average efficiency delta — not just spend totals.
